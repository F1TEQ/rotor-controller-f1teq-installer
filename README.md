# Installateur Web — Rotor Controller F1TEQ Version 1.7.3

Ce dossier est préparé automatiquement par le générateur Windows F1TEQ.

Fichiers principaux :
- `firmware/Rotor_Controller_F1TEQ_V1_7_3_FACTORY.bin` : installation complète USB avec ESP Web Tools ;
- `Rotor_Controller_F1TEQ_UPDATE.bin` : mise à jour de l'application ;
- `manifest.json` : manifeste de l'installateur Web.

Adresse publique :
`https://f1teq.github.io/rotor-controller-f1teq-installer/`

Le fichier UPDATE doit également être joint à la Release GitHub `v1.7.3` pour être détecté par la mise à jour directe depuis l'ESP32.
